Birchie map — three treatment options

This is for the main world map — the storybook artefact Lily opens from the menu and discovers over time. The in-vehicle GPS is a separate, simplified render derived from whichever treatment we pick (preview at the bottom).

A · Painted Storybook

Stardew / Sneaky Sasquatch direction
Painted watercolour wash, hand-drawn cottage icons, hand-lettered town name.
  • + Already matches every other A.R.C. screen — same style language as the cast portraits, the welcome scene, the auth chrome.
  • + Pins read as "places" not abstract markers — kids understand the cottage = the rescue centre, the trees = the woods.
  • – Fewer landmarks before it gets cluttered (~12 cap). Larger map needs zoom levels.
  • – Painted base is the most expensive to commission and re-edit when geography changes.

B · Pictorial Treasure Map

Hundred-Acre-Wood / folk-tale direction
Aged paper, brown-ink linework, sea-creatures + compass rose, scroll labels.
  • + Strongest "story object" feel — feels like Lily found a treasure map, not a UI screen.
  • + Cheap to extend — new landmarks are just brown-ink stamps, no painting.
  • + Reads at every zoom level since linework stays crisp.
  • – Departs from the painted-watercolour treatment used everywhere else.
  • – Lots of small text and ornament — needs careful sizing for 6-year-olds.

C · Faux-3D Diorama

Animal Crossing / Toca direction
Bright cartoon, soft 3/4 perspective, drop-shadows, pill labels.
  • + Highest readability for the youngest end of our age band — every landmark is a little 3D thing.
  • + Easy to extend — add a new landmark by dropping in a new little prop.
  • + Plays well with animated pulses + bouncing pins — fits the friendly motion vocabulary.
  • – Most "game-y" of the three — could feel tonally off next to the painted watercolour rest of A.R.C.
  • – 3/4 perspective fights truthful Birchie geography (real coastal layout reads less clearly).

In-vehicle GPS — derivative, not standalone

Whichever main-map treatment you pick, the dashboard GPS is a stripped-down render of the same data: same coordinates, same landmark IDs, same route line, but cut to only what's relevant on this leg and styled for at-speed glanceability.

GPS · Dashboard view

As Lily would see it while driving Henry to Wyx Park
Simplified, glanceable, sat-nav style — derived from whichever main-map treatment we pick.
  • + Cuts to ~3 visible landmarks: origin (faded), destination, and any hazards on the leg.
  • + High-contrast palette readable while the rest of the dashboard is busy.
  • + Vehicle pin pulses; hedgehog hazards pulse red. Reuses the same animation vocabulary as the main map.
  • – Loses the storybook charm — that's the point. Charm lives on the main map.
